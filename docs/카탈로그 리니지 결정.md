# 데이터 리니지 시각화 도구 선택지

데이터 카탈로그 화면에서 `데이터 흐름도 확인` 버튼을 눌렀을 때 표시할 리니지 팝업 구현 후보를 정리합니다.

| 선택지 | 쉽게 말하면 | 우리 프로젝트에 어울리는 이유 | 어울리지 않거나 조심할 점 | 결론 |
|---|---|---|---|---|
| **React Flow + elkjs** | React 화면 안에서 박스와 선을 그리고, `elkjs`가 위치를 자동 정렬해주는 조합 | 우리 프론트가 이미 React + TypeScript라 붙이기 쉽습니다. 예시처럼 "테이블 카드 안의 컬럼끼리 선 연결"을 만들기 좋고, 확대/축소/드래그/미니맵/컨트롤도 자연스럽습니다. | 그래프 분석 기능 자체는 약합니다. 예를 들어 "가장 영향 큰 노드 찾기" 같은 분석은 직접 구현해야 합니다. | **1순위 추천. 지금 화면에 가장 잘 맞음.** |
| **Cytoscape.js** | 많은 노드와 관계를 탐색하는 네트워크 그래프 전문 도구 | 나중에 데이터셋이 수백~수천 개로 늘고, upstream/downstream 영향도 분석이나 경로 탐색이 중요해지면 강합니다. 큰 관계망을 다루는 데 좋습니다. | React 컴포넌트처럼 예쁜 테이블 카드 UI를 만들기는 React Flow보다 번거롭습니다. 지금처럼 "카탈로그 팝업 안의 보기 좋은 리니지"에는 다소 분석 도구 느낌이 강합니다. | **대규모 그래프 분석까지 갈 때 후보. 지금 MVP에는 과함.** |
| **AntV G6 / Graphin** | 기업형 관계 그래프/지식 그래프를 만드는 시각화 프레임워크 | 관계 분석 화면, 복잡한 노드 스타일, 그래프 탐색 UI를 크게 만들 계획이면 좋습니다. Graphin은 G6 기반 React용 도구라 관계 분석 제품에 어울립니다. | G6 방식의 데이터 구조, 레이아웃, behavior, plugin 개념을 배워야 해서 도입 비용이 큽니다. 우리처럼 빠르게 카탈로그 리니지 팝업을 만들기엔 기능이 많고 무겁습니다. | **장기적으로 그래프 분석 플랫폼처럼 키울 때 고려. 지금은 비추천.** |

## 최종 추천

현재 AskLake는 그래프 분석 제품을 만드는 단계가 아니라, 데이터 카탈로그 안에서 리니지를 보기 좋게 보여주는 팝업을 만드는 상황입니다.

따라서 **React Flow + elkjs** 조합을 우선 추천합니다.
