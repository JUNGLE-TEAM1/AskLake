최종 판정

일반 ETL, 증분 수집, Spark publish, Catalog, 권한, 프론트 UI는 최신 dev 기준으로 동작 확인됨.

다만 source connector의 전체 MinIO/JSON 검증과 Kafka 동시성 테스트는 아직 완전한 녹색이 아니다. mock/local fallback 잔존도 운영 전 정리 대상이다.

품질 게이지는 테스트 결과를 단순 표시한 것이며 제품 품질 점수가 아니다.

미해결·범위 제외

Kafka 동시성 3건

범위 제외

전체 backend 193건 중 Kafka reservation 관련 3건이 실패했다. 현재 구현은 Kafka Snapshot target을 JSONL로 제한하고 있어 기존 fixture가 Parquet 설정으로 호출되며, 외부 ingest 진입 전 검증에서 중단된다.

사용자 결정대로 Kafka continuous/replay는 다른 담당 범위로 분리했다. 따라서 #622 일반 ETL 증분·Spark publish 판정에는 포함하지 않았지만, 전체 dev 녹색 조건에는 남아 있다.

소스 전체 E2E

환경/추가 확인

FastAPI source smoke는 defaults와 CSV까지 통과했지만 JSON metadata 기대값에서 중단됐다. MinIO 기반 전체 source suite는 로컬 MinIO XML endpoint가 준비되지 않아 완료하지 못했다.

확인 로그: File / S3 JSON returned no expected metadata, XML parse error.

Mock/demo fallback 잔존

미해결

frontend/src/hooks/useAskLakeData.ts가 data/mockData를 import하고, dashboard_assistant_service.py에는 OpenAI 실패 시 mock fallback이 남아 있다. 화면/API 경로에서 실제 데이터 실패를 mock 성공처럼 보일 위험이 있다.

이번 점검에서 존재를 확인했지만, 제거 작업은 이 감사 범위에서 수행하지 않았다.

로컬 기본 endpoint

배포 확인 필요

일부 개발 기본값에 localhost/127.0.0.1이 남아 있다. production 환경 변수와 reverse proxy가 실제로 덮는지는 배포 환경에서 별도 검증해야 한다.

검색 대상: frontend API base, source connector, MinIO/Mongo defaults, metadata store.
